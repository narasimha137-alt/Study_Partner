# Study Partner

Study Partner is an AI-powered learning assistant designed to help students improve productivity, organize study materials, and enhance learning through smart academic tools.

## Overview

This project aims to simplify the learning process by combining study management features with AI-assisted learning support. It helps students manage notes, schedules, tasks, and study sessions in a more efficient and organized way.

---

## Features

- AI-powered study assistance
- Smart note organization
- Task and schedule management
- Quiz and question generation
- Study reminders
- Personalized learning support
- Interactive user interface

## Installation

Clone the repository:

```bash
git clone https://github.com/narasimha137-alt/Study_Partner.git
cd Study_Partner
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Running the Project

Start the application:

```bash
python app.py
```
